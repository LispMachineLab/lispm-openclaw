[[https://openclaw.ai][OpenClaw]], the open-source personal assistant that answers wherever you chat with it, as one of
the editor's agents of [[https://github.com/LispMachineLab/lispm-agent][LispM Agent]], beside Claude Code and Codex.  It needs lispm-agent alone
and works in any Emacs 30.1 or later; [[https://github.com/LispMachineLab/lispm-desktop][LispM Desktop]]'s App Store installs it from its
Extensions.  In code, the prefix is ~lispm-openclaw-~.

* What it does

OpenClaw keeps its conversations in its Gateway, a service on this computer or on another, which
its terminal UI, its web UI and its chat channels share.  While ~openclaw~ is on ~PATH~:

- =k= in ~lispm-agents-map~ (=C-c a k= in LispM Desktop, where its agents sidebar and λ menu
  offer it too) has the Gateway make a session working in the current project, and opens
  OpenClaw's own terminal UI, ~openclaw tui~, on it.  Outside projects the session is a chat.  A
  Gateway that cannot work in the project, as one before OpenClaw 2026.10, or one on another
  computer that lacks it, makes a chat instead, and says so.  ~lispm-openclaw-agent~ names the
  OpenClaw agent sessions are made for; by default, the Gateway's default agent.
- Your conversations with OpenClaw join the other agents' sessions in ~lispm-agents-sessions~
  (=C-c a s=): those begun here, in its web UI, or in a chat app such as Telegram, grouped by the
  project each works in, else as chats.  Those of groups, of OpenClaw's subagents and of its
  scheduled jobs are left out.  Resuming one opens the terminal UI on it.
- The sessions are asked of the Gateway through ~openclaw gateway call~, which knows where it is
  and how to be let in, so a Gateway elsewhere serves as well as one here.  Lists of them ask in
  the background, again once OpenClaw's session store here changed, or after
  ~lispm-openclaw-refresh-interval~ seconds.
- Renaming a session gives it a label, which OpenClaw keeps unique; deleting one has the Gateway
  delete it with its transcript, of which it may keep an archive.  OpenClaw refuses to delete an
  agent's main session.  A session's transcript is its conversation, what you wrote and what
  OpenClaw answered, in Markdown.
- ~lispm-agents-send-region~ (=C-c a r=) puts the region, with where it is, into the input of a
  running OpenClaw terminal.

OpenClaw takes MCP servers for its agents in the Gateway alone, not per session, so it sees
nothing of Emacs's state.

Without ~openclaw~ on ~PATH~, OpenClaw shows nowhere, and LispM Desktop's App Store greys it out
with the command installing it.

* Installation

From LispM Desktop's App Store: Extensions, OpenClaw, Get.  Removing it there takes OpenClaw away
from the editor at once; its sessions stay in the Gateway.

By hand, from a checkout, with lispm-agent's =lisp/= on the load path:

#+begin_src emacs-lisp
(add-to-list 'load-path "~/src/lispm-openclaw")
(require 'lispm-openclaw)
(keymap-global-set "C-c a" lispm-agents-map)
#+end_src

OpenClaw itself comes from npm or its install script.  It needs a model provider and a running
Gateway, which =M-x lispm-openclaw-setup= sets up by running ~openclaw onboard~ in a terminal:

#+begin_src sh
curl -fsSL https://openclaw.ai/install.sh | bash
#+end_src

* Tests

#+begin_src sh
make test LISPM_AGENT=../lispm-agent/lisp
#+end_src

They need no OpenClaw: its command is =test/fake-openclaw=, which answers each of the Gateway's
methods as a test tells it to.
